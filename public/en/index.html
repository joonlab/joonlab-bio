04Selected projects

8 projects
  1. 01

    Claude Code agent operating setup and public configuration

    2025 – 2026 · Open source

    I built and use daily a work relay that runs multiple Claude Code sessions back to back, unattended (when the context fills up, it hands off to the next session, and a watcher session handles permission requests), plus a SQLite task board that records state between sessions. I published the general-purpose parts of the setup, split into levels 1 to 4.

    Public configuration repository: 14 stars, 3 forks (2026-11-23)

    Public configuration ↗
    • What the public set includes: a global CLAUDE.md, hooks, slash commands, subagents and 61 general-purpose skills.
    • Safety hooks: blocking dangerous commands, checking that file paths in answers exist, monitoring memory usage, and scanning for secrets before publishing.
    • machines-as-tools: one session calls other Macs through 19 MCP tools and hands them shell and browser tasks. Running across 3 Macs.
    • cmux-state-dashboard: shows dozens of Claude Code sessions on one screen and restores disconnected sessions.
  2. 02

    AI agent web apps and training LMS for LG

    2026.01 – 07 · LG Academy

    I built an interview agent, an agent builder, a multi-agent panel discussion web app, and an LMS for running the courses, and used them in actual training.

    973 total participants, 79 concurrent users with no downtime

    • Next.js, Supabase, Gemini. The conversational practice apps use LangGraph and FastAPI.
    • Several course cohorts can be scheduled at once, and the apps participants build are collected in a gallery.
  3. 03

    TOPIK test item and lecture video pipeline

    2025.11 – 2026.10 · with E4NET · delivered and handed over

    I designed and built a pipeline that runs from item generation through explanations, TTS, slides, video composition and multilingual subtitles, and replaced manual review steps with measurable automatic pass criteria.

    43 explanation videos (341.5 min), 57 videos each in Burmese and Bengali, 45 writing mock-test sets

    • 27 role-specific subagents split the stages; each stage hands off only after its output passes JSON Schema validation.
    • LLMs handle generation; rule engines and scripts enforce deterministic constraints such as a single correct answer, format and sync.
    • All operating assets were handed over in September 2026.
  4. 04

    Seoul Now: real-time city status map

    2026.08 · Public service

    A free web service that puts real-time crowd levels at Seoul landmarks together with traffic, subway, parking, Ttareungyi (Seoul's public bikes), weather and fine particulate (PM2.5/PM10) levels on one map.

    121 places, built on public APIs

    seoul.joonlab98.com ↗
  5. 05

    Fold8 and Mac integration tools (android-mac-lab)

    2026.09 · Open source

    In about a week with Claude Code, I built and published tools that let a Galaxy Z Fold8 work as a Mac's secondary monitor, microphone and remote screen, along with an Android voice agent.

    11 public repositories, 12 stars on the hub repository

    Hub repository ↗
    • deskpad-fold: uses the Fold8 as a secondary monitor for the Mac.
    • fold-agent: tell it what to do and the phone opens apps and taps. Irreversible actions go through a confirmation step defined in code, not by the model.
    • foldmic, clipbridge, fold-cyberdeck, cmux-mobile-remote and others.
  6. 06

    Two-way real-time interpretation subtitles for video meetings (macOS)

    2026.10 · Personal project

    When I speak Korean, subtitles in the other person's language appear only on their screen; when they speak, Korean subtitles appear only on mine. The other person installs nothing.

    Built on Gemini Live translation, with my own engine for language detection and latency handling
